# Urbanic AI Fashion Platform

A fashion and lifestyle e-commerce platform that combines traditional shopping features with AI-driven creative modules, enabling users to shop and co-create fashion designs.

## Overview

This project recreates core functionalities of a shopping website while introducing AI capabilities that transform users from consumers to fashion creators. The platform features a white and purple color theme, emphasizing elegance and simplicity.

## Implemented Features

### Dashboard
Central navigation hub displaying personalized suggestions, trending designs, and quick access to all modules with responsive layout across devices.

### Add to Cart
Shopping cart with real-time updates, quantity adjustment, dynamic price calculation, and product preview functionality.

### Pitch the Makers
AI-powered design generator that converts text descriptions into realistic clothing images. Users can describe their design ideas and generate visual representations using AI text-to-image technology.

### Community Pitches
Social collaboration platform where users can view AI-generated designs, vote on favorites, comment, and share feedback. Connects creators with designers and manufacturers for real-world production.

## Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript, React.js
- **Backend**: Node.js with Express.js
- **Database**: MongoDB
- **AI Integration**: OpenAI / Stable Diffusion API
- **Version Control**: Git and GitHub
- **Project Management**: JIRA (Agile Scrum)
- **Deployment**: Vercel / Netlify

## Project Management

- **Model**: Agile Scrum with iterative development
- **Tool**: JIRA for sprint planning and task tracking
- **Approach**: Incremental delivery with regular sprint reviews
